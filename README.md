# About
**View the web app here:** [recipe-lists](https://recipe-lists.vercel.app)

This project is a web app on recipes, that is based on a mock API (made with <i>https://my-json-server.typicode.com</i>)

The main page lists down the different types of cuisines and each cuisine, when clicked will bring viewers to the respective recipes.

### Features
1) Each recipe comes with the following information: 
    - Name of dish
    - Type of dish
    - Prep time
    - Cook time
    - Number of servings
    - Calories per serving
    - Ingredients
    - Instructions
2) At the bottom of each recipe page has two buttons:
    - Back to the page with list of cuisines
    - To the top of the page shortcut
